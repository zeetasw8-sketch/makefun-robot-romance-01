# Robot Romance: One-Line Pickup Lines for AI

A single-line pickup line written to charm a robot or an AI — one breath, three beats: a context window, 96 attention heads, 128,000 tokens, and a jealous system prompt.

> Are you my context window, because I gave all 96 of my attention heads to you, saved 128,000 tokens of us, and my system prompt just filed a jealousy complaint.

## Run

```bash
node main.ts
```

`main.ts` reads `line.txt` in the same directory, validates it (1–200 characters, a single sentence), and writes the exact same bytes to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` if the variable is not set), with no trailing newline.
